Visualizador de Visibilidad de Eclipse
Este proyecto implementa un visualizador cartográfico web para el análisis de la visibilidad de eclipses desde el territorio nacional. 
El visor se apoya en la API‑CNIG para la representación geográfica y utiliza capas raster y vectoriales que modelizan la trayectoria del eclipse, las zonas de visibilidad y los parámetros astronómicos asociados. 
La aplicación permite consultar de forma interactiva la visibilidad parcial o total del fenómeno en función de la localización, facilitando la divulgación científica y el apoyo técnico a estudios astronómicos. 
El diseño sigue criterios de reutilización, rendimiento y coherencia cartográfica institucional.
